# 矿山安全教育游戏

一个基于Web的矿山安全教育游戏，结合飞行射击游戏和知识问答，帮助用户学习矿山安全知识。

## 功能特性

### 1. 登录系统
- 用户名登录界面
- 简洁的登录表单

### 2. 开始与选择界面
- **开始游戏**：进入飞机飞行游戏
- **理论学习**：进入理论学习界面

### 3. 理论学习系统
- 8个安全分类：
  - 法律法规与总则
  - 通风与瓦斯防治
  - 爆炸与火灾防治
  - 矿井水害防治
  - 顶板与冲击地压防治
  - 爆破与爆炸物品管理
  - 运输提升与电气安全
  - 职业健康与应急避险
    每个分类包含 50道题目（20道判断题和30道选择题）
    题目类型：选择题和判断题
    显示答案和详细解析

### 4. 飞机飞行游戏
- **操作方式**：
  - WASD：控制玩家飞机移动
  - 空格键：发射子弹
- **游戏机制**：
  - 初始弹药：10发
  - 敌机持续出现
  - 敌机随机发射子弹
  - 每一关卡消灭60架敌机并且答题正确数量在40道以上获胜
  - 被敌机或敌机子弹击中失败
- **知识问答**：
  - 弹药为0时按下攻击键触发
  - 随机抽取5道题目
  - 答对几道题获得几发弹药
  - 显示准确率和获得弹药数

### 5. 结果界面
- **通关失败**：
  - 进入下一关卡
  - 回顾知识
- **通关成功**：
  - 重新挑战
  - 回顾知识

## 安装步骤

### 1. 环境要求
- Node.js (v14.0.0 或更高版本)
- npm (v6.0.0 或更高版本)

### 2. 安装依赖
```bash
cd /workspace/安全教育游戏
npm install
```

### 3. 启动服务器
```bash
node server.js
```

### 4. 访问游戏
在浏览器中打开：`http://localhost:3000`

## 游戏玩法

### 1. 登录游戏
1. 打开游戏页面
2. 输入用户名
3. 点击"登录"按钮

### 2. 选择模式
- **开始游戏**：进入飞行射击游戏
- **理论学习**：学习矿山安全知识

### 3. 理论学习
1. 点击任意安全分类按钮
2. 查看该分类的所有题目
3. 学习答案和解析
4. 点击"返回"按钮回到主菜单

### 4. 飞行游戏
1. 使用WASD控制飞机移动
2. 按空格键发射子弹攻击敌机
3. 弹药耗尽时按空格键进入问答
4. 答对题目获得弹药继续游戏
5. 每一关卡消灭60架敌机并且答题正确数量在40道以上获胜，否则失败，只能继续玩现在的游戏

### 5. 知识问答
1. 阅读题目
2. 选择正确答案
3. 查看答案解析
4. 完成所有题目后查看结果
5. 点击"继续游戏"返回飞行游戏

## API接口

### 获取所有题目
```
GET /api/questions
```

### 获取指定分类题目
```
GET /api/questions/:category
```

### 获取随机题目
```
GET /api/random-questions?count=10
```

### 获取所有分类
```
GET /api/categories
```

## 题目数据结构

```json
{
  "分类名称": [
    {
      "type": "choice",  // 题目类型：choice(选择题) 或 judgment(判断题)
      "question": "题目内容",
      "options": ["选项A", "选项B", "选项C", "选项D"],  // 选择题才有
      "answer": "正确答案",  // 选择题为选项内容，判断题为true/false
      "explanation": "答案解析"
    }
  ]
}
```

## 开发说明

### 添加新题目
编辑`questions.json`文件，按照现有格式添加新题目。

### 修改游戏参数
在`game.js`中可以修改以下参数：
- `this.ammo = 10` - 初始弹药数量
- `this.enemyCount = 2` - 初始敌机数量
- 胜利条件中的数字 - 需要消灭的敌机数量

### 自定义样式
编辑`style.css`文件可以修改游戏的外观和布局。
